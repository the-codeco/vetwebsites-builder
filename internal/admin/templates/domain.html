Set it up

  1. Run the site on a server with a public IP address and ports 80 and 443 open to the internet, using the production setup (see docs/DEPLOY.md): 
    docker compose --profile prod up -d
    with SECURE_COOKIES=true and TRUST_PROXY=true in your .env.
  2. Point your domain at the server by adding these records where you manage your DNS:
    TypeNameValue
    A{{if .Data.Current}}{{.Data.Current}}{{else}}example.com{{end}} (or @)your server's IPv4 address
    AAAAsameyour server's IPv6 address (only if it has one)
    CNAMEwww{{if .Data.Current}}{{.Data.Current}}{{else}}example.com{{end}} (or an A record with the same IP)

    Your hosting provider shows the server's IP address in its dashboard. DNS changes can take a few minutes to a few hours.

  3. Save the domain above, then run the check below.
  4. The first visit over HTTPS makes the server request a free certificate (from Let's Encrypt). That takes a few seconds, and it only happens for the domain you saved here.
