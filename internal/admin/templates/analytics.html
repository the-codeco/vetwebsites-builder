Privacy

Analytics is built in. It sets no cookies, loads no outside scripts and sends nothing to anyone, so visitors don't need a consent banner for it. Each visit stores the page, the referring website, a device type, a browser name and an anonymous code that changes every day — never an IP address. Logged-in users, bots, drafts and previews are not counted, and neither are visitors who send “Do Not Track”. Data older than {{.Data.Retention}} days is deleted automatically.
